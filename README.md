## Applications

The following applications can be used to customize Discord:
1. [Vencord](https://vencord.dev) - a Discord modification with support for plugins and themes.  
2. [BetterDiscord](https://betterdiscord.app) - another version for customizing Discord.

## Installation & setup

### Vencord
Download Vencord from the [official website](https://vencord.dev/download/#windows).  
Follow the installation instructions.  
Open Discord and configure your plugins and themes.

### BetterDiscord

You can download BetterDiscord from the [official website](https://betterdiscord.app).  
Or browse the [BetterDiscord themes directory](https://betterdiscord.app/themes) and choose a theme you like.  
Theme I use: [Discord+](https://betterdiscord.app/themes/Discord%2B)  
I use Discord+ because of its customizable appearance and visual style.

## Useful Vencord plugins

These are some of the plugins I find most useful:

| Plugin | Description |
|:---|:---|
| **BlurNSFW** | Blurs attachments in NSFW channels. |
| **DisableCallIdle** | Prevents automatic disconnection from idle DM voice calls. |
| **FakeNitro** | Provides certain Nitro-like features. |
| **NoUnblockToJump** | Allows jumping to messages from blocked users. |
| **Translate** | Translates messages directly in Discord. |
| **ValidReply** | Helps fix the "Message couldn't be loaded" issue. |
| **VolumeBooster** | Allows higher volume levels for users and streams. |

I use additional plugins, but these are the ones I find most useful.
